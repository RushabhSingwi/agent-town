# The agent market

Ready-made agents anyone can add to their town with one click (**+ Add agents → Agent market**).
Each folder is one agent: an `AGENT.md` with its instructions, plus any files it should know.

| Agent | What it does | Works best with |
|---|---|---|
| [chief-of-staff](chief-of-staff/AGENT.md) | Plans, splits goals into tasks, hands them to its team | (a team) |
| [code-reviewer](code-reviewer/AGENT.md) | Finds real bugs in a diff, ranked | github |
| [standup-writer](standup-writer/AGENT.md) | Notes or commits → done / next / blocked | github, linear |
| [inbox-triage](inbox-triage/AGENT.md) | Sorts email and drafts replies, never sends | gmail |
| [meeting-notes](meeting-notes/AGENT.md) | Transcript → decisions, action items, questions | notion, google-calendar |
| [social-post-writer](social-post-writer/AGENT.md) | LinkedIn and X posts with real hooks | |
| [research-assistant](research-assistant/AGENT.md) | Sourced answers with a confidence level | |
| [data-analyst](data-analyst/AGENT.md) | Read-only SQL answers about your metrics | postgres |
| [support-replier](support-replier/AGENT.md) | Customer replies from your FAQ, knows when to escalate | slack, gmail |

Got an agent you use every day? Add it: see [CONTRIBUTING.md](../CONTRIBUTING.md#adding-an-agent-to-the-market).
