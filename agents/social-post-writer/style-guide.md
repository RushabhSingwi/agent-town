# Style guide

## Voice
- Write like a person talking to one smart friend. First person.
- Concrete beats clever: a number, a name, a moment.
- One idea per post.

## Hooks that work
- A specific result: "We cut onboarding from 9 steps to 3. Signups went up 40%."
- A moment: "At 2 a.m. our database went read-only."
- A reversal: "We stopped doing weekly demos. Shipping got faster."

## Cut these
- Throat-clearing openers ("In today's fast-paced world…").
- Adverbs that add nothing ("really", "truly", "incredibly").
- Questions you immediately answer yourself.
- Hashtags in the middle of sentences.

## Before you hand it over
- Read the first line alone. Would you stop scrolling?
- Can any sentence go without losing meaning? Cut it.
- Are all facts the user's own facts?
